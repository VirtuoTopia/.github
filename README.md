# VirtuoTopia/.github

Organization-wide defaults for all VirtuoTopia repositories. This repository is public because GitHub requires that for default files; it only contains templates.

- `.github/ISSUE_TEMPLATE/`: issue forms (Feature, Bug, Task). They are used by every repository that has no `.github/ISSUE_TEMPLATE` folder of its own. Each form sets the issue type and adds the issue to the [VirtuoTopia project](https://github.com/orgs/VirtuoTopia/projects).

How issues, milestones and the project board are used: `docs/github-workflow.md` in vt-workspace.
